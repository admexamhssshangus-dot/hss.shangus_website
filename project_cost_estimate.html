🏗 Architecture Breakdown & Modernization Analysis

The platform has transitioned from a fragmented Google Apps Script architecture into a unified, high-performance, reactive full-stack web application. The 181,795 lines of active code are structured across 5 specialized architectural pillars:

  • Admin Portal Suite (83,392 LOC): Advanced Reports BI Engine, Certificate Studio, Custom Roster Document Builder, Admission Gazette, Consolidated Tabulation Engine, Fund Distribution Ledger, Direct Ingestion, and Official Letter Writer.
  • Teacher Portal (9,248 LOC): Stream-based digital attendance matrix, practical lab marks evaluation grids, automated 50M scaling, and real-time revision sync.

  • Portal Framework & Dynamic Engine (5,957 LOC): Schema-driven form generator, session validation, role routing, and responsive tab layout shell.

2. Client-Side Document & Render Engines (10.9% • 19,807 LOC)

Zero-server rendering architecture allowing instant, client-side generation of high-resolution institutional documents:

  • PDF Auto-Table Generator: Dynamic gazettes, multi-column tabulation, automated page splitting, and watermarks.
  • Vector Canvas Certificate Studio: WYSIWYG certificate template designer with drag-and-drop text/badge layers.
  • DOCX Office Exporters: Real-time XML zip construction of editable official correspondence and rosters.
  • ID Card & QR Suite: High-density batch student ID cards with embedded cryptographic QR verification.

3. Public Web Experience & Dashboards (16.3% • 29,558 LOC)

High-engagement institutional web portal designed with glassmorphism and modern web ergonomics:

  • Institutional Portals & Pages (20,942 LOC): Academics, Stream Selector, Faculty Showcase, Examination News, Public Result Lookup, Legal Disclaimers, and Unified Portal Navigation Hub.
  • Component Design System (7,227 LOC): Dynamic Navbar with responsive mobile drawer, animated hero carousels, accessible modals, notification toasts, and bespoke Tailwind styling.
  • Root Runtime (1,389 LOC): Strict React 19 concurrent root, global error boundaries, lazy chunk prefetchers, and dynamic code splitting.

4. Cloud Data, Caching & Serverless (9.7% • 17,618 LOC)

Cloud-native backend leveraging Google Cloud / Firebase serverless infrastructure:

  • Multi-Tier Caching Layer (dbCache.js - 2,014 LOC): Transparent IndexedDB client caching with sub-millisecond query responses and offline availability.
  • Firebase Services (9,590 LOC): Granular collection architecture with atomic batch writes, real-time Firestore listeners, and version bin service.
  • Security & Edge Infrastructure (8,028 LOC): Granular Firestore Security Rules, Netlify Edge serverless endpoints, and Firebase Cloud Functions.

5. DevOps, Automated Testing & Ingestion Tooling (6.1% • 11,139 LOC)
