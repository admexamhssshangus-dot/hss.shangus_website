🏗 Architecture Breakdown & Modernization Analysis

The platform has transitioned from a fragmented Google Apps Script architecture into a unified, high-performance, reactive full-stack web application. The 145,817 lines of active code are structured across 5 specialized architectural pillars:

1. Multi-Portal Enterprise ERP (56.1% • 81,784 LOC)

Unified administrative and operational governance suite for faculty, administration, and students:

  • Admin Portal Suite (65,477 LOC): Advanced Reports BI Engine, Certificate Studio, Custom Roster Document Builder, Admission Gazette, Fund Distribution Ledger, Direct Bulk Ingestion Modal, and Official Letter Writer.
  • Teacher Portal (6,921 LOC): Stream-based digital attendance registers, practical lab evaluation grids, automated grade calculation.
  • Student Portal (4,392 LOC): Multi-stream provisional and full admission self-service, document upload, and status tracker.
  • Portal Framework & Dynamic Forms (5,364 LOC): Schema-driven form generator, session validation, and layout shell.

2. Client-Side Document & Render Engines (11.1% • 16,140 LOC)

Zero-server rendering architecture allowing instant, client-side generation of high-resolution institutional documents:

  • PDF Auto-Table Generator: Dynamic gazettes, multi-column tabulation, automated page splitting, and watermarks.
  • Vector Canvas Certificate Studio: WYSIWYG certificate template designer with drag-and-drop text/badge layers.
  • DOCX Office Exporters: Real-time XML zip construction of editable official correspondence and rosters.
  • ID Card & QR Suite: High-density batch student ID cards with embedded cryptographic QR verification.

3. Public Web Experience & Dashboards (14.7% • 21,429 LOC)

High-engagement institutional web portal designed with glassmorphism and modern web ergonomics:

  • Institutional Portals & Pages (17,177 LOC): Academics, Stream Selector, Faculty Showcase, Examination News, Legal Disclaimers, and Unified Portal Navigation Hub.
  • Component Design System (3,626 LOC): Dynamic Navbar with responsive mobile drawer, animated hero carousels, accessible modals, and notification toasts.
  • Root Runtime (626 LOC): Strict React 19 concurrent root, global error boundaries, and dynamic code splitting.

4. Cloud Data, Caching & Serverless (9.4% • 13,705 LOC)

Cloud-native backend leveraging Google Cloud / Firebase serverless infrastructure:

  • Multi-Tier Caching Layer (dbCache.js - 2,019 LOC): Transparent IndexedDB client caching with sub-millisecond query responses and offline availability.
  • Firebase Firestore & Cloud Storage: Granular collection architecture with atomic batch writes and transactional ledger commits.
  • Security & Edge Infrastructure (3,648 LOC): Granular Firestore Security Rules, Netlify Edge serverless functions, and Firebase Cloud Functions.

5. DevOps, Automated Testing & Ingestion Tooling (7.1% • 10,420 LOC)

Comprehensive engineering toolset guaranteeing enterprise data integrity and regression safety:

  • Regression Test Harnesses: Dedicated regression suites for admission validation, student promotion, fee distribution integrity, and role security.
  • High-Throughput Data Ingestion: Automated sanitizers, historical Excel/CSV parsers, and schema synchronizers.
  • Database Maintenance Scripts: Cache invalidators, schema migration utilities, and automated build verifiers.
