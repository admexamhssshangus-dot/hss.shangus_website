🚀  Ultimate Beginner's Guide: Building Govt HS S  ERP in React
Welcome! Don't worry if you haven't used React before. React is just JavaScript that lets you
build your own custom HTML tags (called "Components"). Instead of writing one massive HTML
file, we will create small building blocks (like a <Navbar /> and a <Footer />) and put them
together.
Let's build your school system step-by-step.
Step 1: Install the Prerequisites
Before we code, your computer needs the software that runs JavaScript locally.
1. Download Node.js: Go to nodejs.org and download the "LTS" (Long Term Support)
version. Install it like any normal program.
2. Open VS Code: Open your empty folder (Govt-HSS-ERP) in VS Code.
3. Open Terminal: Inside VS Code, click Terminal -> New Terminal at the top.
Step 2: Create the React App
In your VS Code terminal, type this exact command and press Enter:
npx create-react-app frontend
What this does: It downloads all the necessary files to run a React project into a new folder
called frontend.
Once it finishes (it might take a minute), move into that folder by typing:
cd frontend
Step 3: Install Tailwind CSS & Icons (Stable Version)
We need Tailwind to make the design look like your WordPress site. Note: We use
tailwindcss@3 to ensure compatibility with standard React setups and avoid PostCSS build
errors.
Run these commands one by one in the terminal:
npm install -D tailwindcss@3 postcss autoprefixer
npx tailwindcss init -p
npm install lucide-react react-router-dom
